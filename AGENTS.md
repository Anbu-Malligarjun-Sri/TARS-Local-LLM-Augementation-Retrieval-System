# TARS project context

Before implementing or changing architecture, read:

1. `context/project-overview.md`
2. `context/architecture.md`
3. `context/ui-context.md`
4. `context/code-standards.md`
5. `context/ai-workflow-rules.md`
6. `context/progress-tracker.md`

Then read the active spec under `context/specs/`. The detailed baseline and roadmap are in `docs/TARS_ARCHITECTURE_PLAN.md`. Distinguish existing code from proposed capabilities. Preserve user data and pre-existing changes. Update the progress tracker after meaningful work and relevant context files when implementation changes their assumptions.

The root `context/` folder is canonical. `Six-File+Context+Methodology/` contains the supplied reference/templates, not a second active context set.
