# R1 first unit · visitor lifecycle

Implement a separately runnable, single-process loopback FastAPI app for creating, checking and ending a 15-minute visit. Its sole credential is an opaque, scoped HttpOnly cookie. Renewing the page or repeating create must preserve the original expiry. Distinct visitors cannot select each other by ID. Keep only digests and monotonic deadlines in bounded process memory. Expired, ended and restarted visits lose access. Bound live visits and remove idle expired entries. Reject foreign browser origins and simple cross-site form writes. Disable API schema routes. Use no owner modules, files, provider keys or paid inference. Verify the HTTP contract with two isolated browsers, expiry, saturation, idempotent retry, cookie attributes and forbidden desktop routes. Streaming turns and Stop are subsequent R1 units.
